# Power BI Internship Projects

## Overview

This repository contains four interactive Power BI dashboards developed as part of my internship project.

The projects cover Financial Analysis, HR Analytics, Real Estate Market Trends, and Educational Performance & Resource Allocation.

## Projects

### 1. Financial Health Dashboard
Analysis of financial performance, profitability, cash flow, budgeting, and revenue forecasting.

### 2. HR Analytics Dashboard
Analysis of employee attrition, recruitment, satisfaction, performance, and hiring trends.

### 3. Real Estate Market Trends Dashboard
Analysis of property prices, rental yield, supply and demand, interest rates, and geographical trends.

### 4. Educational Performance & Resource Allocation Dashboard
Analysis of student performance, attendance, academic results, and educational resource allocation.

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel
